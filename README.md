<details open>
<summary><b>🔹 ReadsDot AI — Braille Detection & Translation</b></summary>
<br/>

Accessibility-focused computer vision web application that detects and translates Braille directly inside the browser using a YOLOv8 model converted to ONNX — requiring **zero backend inference**.

| Attribute | Detail |
|---|---|
| **Stack** | React · TypeScript · YOLOv8 · ONNX Runtime Web · Tailwind CSS |
| **Scale** | Fully client-side inference pipeline, no server dependency |
| **Performance** | Real-time detection via optimized in-browser ONNX execution |
| **Security** | No image data leaves the client — 100% local processing |
| **Impact** | Accessibility tool enabling Braille-to-text and text-to-Braille conversion for visually impaired users |
| **Repository** | [github.com/Guna-garan/ReadsDot](https://github.com/Guna-garan/ReadsDot) |

Engineered a custom preprocessing pipeline using the Canvas API — grayscale conversion, adaptive thresholding, dot grouping, and character mapping — paired with a bidirectional Text-to-Braille conversion engine, delivering a complete assistive-technology product without any server-side dependency.

</details>
